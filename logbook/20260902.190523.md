### Lambda functions (CloudFormation-managed)
- `PartyLineSmaFunction` (`sma.js`) — call control: answer, record, greet, create meeting + attendee, create the capture pipeline, create the media stream pipeline, join the call into the meeting, start live transcription, handle `CALL_UPDATE_REQUESTED` (plays the drum roll), handle `HANGUP` (tears down meeting + capture pipeline)
- `PartyLineSweepFunction` (`sweep.js`) — dev-only cost safety net, force-ends any meeting older than 4 hours, on a fixed schedule (00:00, 04:00, 08:00 UTC, not DST-adjusted)
- `PartyLineStreamEventFunction` (`stream-event.js`) — EventBridge-triggered on `chime:MediaPipelineKinesisVideoStreamStart`, launches the Fargate consumer task with the KVS stream ARN and meeting ID

### Real-time voice trigger (Fargate — new today, replacing an abandoned direct-Lambda approach)
- ECR repository `lovely-system-sandbox-partyline-kvs-consumer` — image pushed, tag `:latest`
- ECS cluster `lovely-system-sandbox-partyline`
- ECS task definition `lovely-system-sandbox-partyline-kvs-consumer:1` — Fargate, 512 CPU / 1024 memory, `awsvpc` networking
- Task role and execution role (separate — task role has `kinesisvideo:GetMedia`/`GetDataEndpoint` on `ChimeMediaPipelines-*` streams, `transcribe:StartStreamTranscription`, `chime:UpdateSipMediaApplicationCall`, `dynamodb:Scan` on the calls table)
- Security group `sg-0789dae4208481729` — outbound `tcp/443` only (tightened this session from an initial `-1`/`0.0.0.0/0` rule, caught and named by the operator as "promiscuous")

- Container (`src/containers/kvs-consumer/index.js`): reads the raw KVS stream, decodes AAC→PCM via `ffmpeg`, streams PCM to Amazon Transcribe Streaming, watches final results for "drum roll please", resolves the call by `meeting_id` from DynamoDB, calls `UpdateSipMediaApplicationCall`
