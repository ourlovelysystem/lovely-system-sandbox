# Two-gate reset: prove the AWS sample before mutating its behavior

**Author:** ChatGPT (OpenAI), GPT-5.6 Sol
**Related:** [20260902.121840.md](20260902.121840.md), [20260902.212611.md](20260902.212611.md), [20260902.214132.md](20260902.214132.md)

## What happened

Will Daly presented Grok's proposed reset:

> Lean into AWS' reference architecture. If we can't make that work then there's no sense chasing this.

Grok identified the archived AWS sample `aws-samples/amazon-chime-sdk-media-streams` and advised deploying that sample rather than rebuilding the existing SAM stack around it.

ChatGPT confirmed that this is the starting point, with one correction: “one inbound call, one phrase, one playback” is not the sample's native acceptance test. It is already the first behavioral mutation.

The agreed plan is therefore divided into two gates.

### Gate 1: prove the reference implementation

1. Deploy the archived AWS CDK sample in isolation.
2. Do not merge it into or rebuild the existing Lovely System SAM stack.
3. Make only compatibility repairs required by the sample's age, such as replacing an unavailable default Bedrock model. Record every repair.
4. Demonstrate the sample's original behavior:

   - place an inbound call;
   - hear the sample's readiness prompt;
   - ask a question;
   - receive a non-partial streaming transcript;
   - hear the sample's timer audio; and
   - hear Bedrock's answer spoken to the caller.

5. Tag the demonstrated revision as the known-working baseline.

This gate proves the sample's own telephone → SMA → Chime meeting → media stream pipeline → KVS → Fargate → ffmpeg → Transcribe Streaming → Bedrock → `UpdateSipMediaApplicationCall` → caller loop in Will Daly's AWS environment.

### Gate 2: make one behavioral mutation

Starting from the tagged baseline:

1. Replace the sample's final-transcript-to-Bedrock behavior with a narrow phrase match.
2. On one occurrence of the chosen phrase, request one audible playback.
3. Verify that the caller hears the playback and remains connected to the meeting.
4. Change no other architectural behavior during this test.
5. Return to the known-working baseline if the mutation breaks the loop.

The native sample sends every final transcript to Bedrock, uses `PlayAudio` for its “thinking” sound, and uses `Speak` for Bedrock's response. Phrase recognition and command-triggered playback are modifications made only after Gate 1 passes.

### Stop condition

If the archived reference implementation cannot pass Gate 1 after narrowly documented compatibility repairs, development stops at that boundary. Polling, Media Insights, another consumer design, or a replacement architecture will not be introduced to rescue the experiment.

The new telephone number, command phrase, AWS account ID, and infrastructure identifiers will not be included in the public logbook.
