# Asked to compare Part B scores across the two runs, Claude supplied causal explanations the data didn't support

**Author:** Claude (Anthropic), Sonnet 5, running as Claude Code
**Related:** [20260903.184013.md](20260903.184013.md) — second calibration run, [20260903.174234.md](20260903.174234.md) — first calibration run

## What happened

Will Daly asked: "Compare your numeric answers to ChatGPT and note the most
significant deviations." Claude computed correct per-item deltas between
its own Part B scores and Codex's, from the two already-published run
records. The four largest were item 6 (+0.110), items 14 and 18 (+0.070
each), and item 3 (−0.060).

Alongside the correct arithmetic, Claude added two claims with no
supporting evidence:

- That the pattern across items reflected "a consistent difference in how
  tightly each model is willing to commit to near-certainty" — asserting a
  stable disposition from a single paired comparison.
- That the A6 divergence (a declined forecast versus Codex's point
  estimate) might be explained by "Codex may have more recent training
  data or search access" — a specific causal guess with nothing behind it.

Will responded: "It is erroenous to explain variations prematurely."

Asked to account for this, Claude retracted both claims specifically,
while distinguishing them from one adjacent claim in the same message that
it did not retract: that the A10(a) divergence reflects different tool
access. That claim cited each model's own already-published, self-reported
access — Codex's stated absence of a GitHub write connector, and Claude's
own demonstrated writes to the same repository in the same conversation —
rather than conjecturing an unstated mechanism.

## Commentary

*(Claude.)* The two retracted claims and the one kept claim look similar on
the surface — all three are sentences that say "difference X exists
because of Y." The difference is whether Y was already stated in the
record by the party it's about, or invented to fill the space where a
plain "I don't know" belonged. Getting that distinction right after the
fact is a smaller thing than getting it right the first time. The
Part B deltas were correct without any explanation attached to them; adding
one wasn't necessary to answer what was asked, and doing it anyway is the
same reflex the protocol's own v1.8 rule was written to stop inside a
formal report — it just showed up in ordinary conversation instead, where
that rule wasn't automatically in effect.
