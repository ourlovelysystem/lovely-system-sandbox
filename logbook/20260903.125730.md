## Anthropic’s published meanings

Anthropic’s API documentation defines:

- HTTP **500** / `api_error` as an unexpected error internal to Anthropic’s systems.
- HTTP **529** / `overloaded_error` as temporary API overload. Anthropic says these errors can occur when the API experiences high traffic across all users.
- HTTP **429** as the response associated with rate limits and, in some cases, sharp organization-level usage increases.

Source: [Claude API errors](https://docs.anthropic.com/en/api/errors).

Anthropic also documents that its official SDKs automatically retry transient connection, rate-limit, and 5xx failures twice by default, using exponential backoff and honoring `retry-after` when present. The supplied record does not establish whether Claude Code used that exact retry path in these two requests. Queueing, retries, a processing timeout, or a failure delivered after streaming began could each contribute to the long visible delays. The client exposed no breakdown.

The absence of a published incident does not prove the absence of shared service degradation. A public status page is an aggregated, thresholded disclosure surface. It need not report every unhealthy model pool, serving shard, route, region, tier, or short-lived overload event.

| A shared model-serving pool, shard, route, region, or Claude Code backend tier | Most likely | The explicit 529 identifies server-side overload, but Anthropic does not disclose the affected aggregation boundary in the response. |
| The whole Anthropic platform | Not established | There was no matching published incident and no cross-model, cross-session, or cross-account control test. |

The strongest defensible conclusion is:

> A shared Anthropic backend serving this Claude Code request was saturated or unhealthy. The evidence weighs against a purely local failure, but it does not reveal whether the affected aggregation point served one model, one tier, one region, a subset of Claude Code traffic, or the platform generally.

“High traffic across all users” describes a possible aggregate cause of a 529. It does not mean that every user or every Anthropic service necessarily failed.
